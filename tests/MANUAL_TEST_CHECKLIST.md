# เช็กลิสต์ทดสอบบนเครื่องจริง (ทำก่อนออกอัปเดต)

เทสต์อัตโนมัติ (`npm test`) ครอบคลุมตรรกะและขั้นตอนของระบบแล้ว แต่ไม่ครอบคลุม LINE/SlipOK จริง, tunnel, ตัวอัปเดต และหน้าตาบนเบราว์เซอร์
ไฟล์นี้คือส่วนที่คนต้องทดสอบเองด้วย **บัญชี LINE OA ทดสอบ + บัญชีธนาคารทดสอบ** ก่อนปล่อยให้ร้านใช้จริง (ห้ามทดสอบบนข้อมูลร้านจริง ให้ใช้ฐานข้อมูลใหม่หรือสำรอง `data.sqlite` ก่อน)

ตั้งค่าตั้งต้น: ราคาสินค้า 2 รายการ (เช่น A=100, B=200), ค่าส่ง 40, ส่งฟรีเมื่อครบ 3 ชิ้น, ตั้งชื่อบัญชีรับเงินให้ตรงกับบัญชีทดสอบ

## ก. เปิดโปรแกรม

- [ ] หน้าตั้งค่าผู้ให้บริการสลิป: โลโก้ SlipOK / EasySlip / Thunder / SlipVerify ขึ้นครบ (ไม่ใช่รูปแตก)
- [ ] มีไฟล์ `system.log` ข้างโปรแกรม และมีบรรทัดใหม่เพิ่มเมื่อทำอะไรสักอย่าง

## ข. ยอดนอกรอบไลฟ์ (กติกา ก)
- [ ] **ก่อนกดเริ่มไลฟ์:** ลูกค้าทดสอบ 1 โอนเงินพอซื้อ 1 ชิ้นพร้อมค่าส่ง (140) สลิปเข้าคิวรอ และ**การ์ดติดป้ายม่วง "🕒 โอนนอกรอบ"**
- [ ] กด "เริ่มไลฟ์" → คิวของลูกค้า 1 **ยังอยู่** ในหน้าคิว ยอดรวมของรอบนับ 140 และ**ป้าย 🕒 ยังติดอยู่บนการ์ด** (ส่วนลูกค้าที่โอนระหว่างไลฟ์ไม่มีป้าย)
- [ ] เปิดหน้าต่าง Export Kerry → มีแถบม่วงแจ้งรายชื่อลูกค้า "โอนนอกรอบ" / ดาวน์โหลดไฟล์ Excel → ช่อง Remark ต้อง**ไม่มี**ข้อความ "โอนนอกรอบ" (ไฟล์นี้อัปโหลดให้ Kerry)
- [ ] **หน้าประวัติ:** ก่อนเริ่มไลฟ์ แถวของลูกค้า 1 ขึ้น "🕒 นอกรอบ — รอผูกเข้ารอบถัดไป" → หลังเริ่มไลฟ์ เปลี่ยนเป็นชื่อรอบพร้อมป้ายม่วง "🕒 โอนนอกรอบ→รอบนี้" และตาราง "ยอดโอนแยกตามรอบไลฟ์" ของรอบนั้นมีป้าย "🕒 รับยอดนอกรอบ 1 ใบ"
- [ ] ระหว่างไลฟ์ ลูกค้า 1 โอนเพิ่ม 100 → ได้ 1 ชิ้น **ไม่ถูกเก็บค่าส่งซ้ำ**
- [ ] จบไลฟ์รอบ A, ลูกค้าทดสอบ 2 โอน 140 (ระหว่างรอบ) แล้วเริ่มไลฟ์รอบ B → คิวของลูกค้า 2 อยู่ในรอบ B ไม่ใช่รอบ A
- [ ] สลิปที่แม่ค้ากด "เสร็จสิ้น/ปัดตก/เคลียร์" แล้วก่อนเริ่มไลฟ์ **ไม่** ถูกดึงเข้ารอบใหม่
- [ ] ลูกค้าที่โอนไม่พอ (เช่น 60) แล้วเริ่มไลฟ์ → หน้าต่างเตือนยอดค้างขึ้นตามเดิม และยอดในกระเป๋าเป็น 0 หลังเริ่ม (กติกา v1.0.13)

## ค. สลิปที่ระบบไม่บันทึก ต้องมีการ์ดเตือน
- [ ] โอนเข้าบัญชีอื่น (ชื่อไม่ตรง) → ขึ้นการ์ดแดงบอกชื่อบัญชีที่โอนเข้าและยอด, ไม่เข้าคิว, กด "รับทราบ" แล้วการ์ดหาย
- [ ] ลูกค้าคนเดิมส่งสลิปใบเดิมซ้ำ → ไม่มีคิวซ้ำ และไม่มีการ์ด (มีแค่บรรทัดใน Logs)
- [ ] ลูกค้าอีกคนส่งสลิปใบเดียวกัน → ขึ้นการ์ดว่าเคยบันทึกให้ลูกค้าคนแรกแล้ว
- [ ] ปัดตกสลิปหนึ่งใบ แล้วลูกค้าส่งใบเดิมอีก → ขึ้นการ์ดว่าถูกปัดตกไปแล้ว
- [ ] ส่งรูปที่ไม่ใช่สลิป → เข้าคิว "ตรวจสลิปเอง" (ไม่หาย)
- [ ] ปิดเน็ตชั่วคราวตอนลูกค้าส่งสลิป → การ์ดแดง "โหลดรูปสลิปไม่สำเร็จ"
- [ ] การ์ดที่ขึ้นก่อนกดเริ่มไลฟ์ ยังเห็นหลังกดเริ่มไลฟ์

## ง. Dashboard และ Kerry ระหว่างไลฟ์
- [ ] ระหว่างไลฟ์ กดรีเฟรชหน้า (F5) → ตัวเลขยอดรวม/จำนวนลูกค้าเป็นของรอบไลฟ์ทันที ไม่ต้องรอสลิปใหม่

- [ ] เปิดหน้าต่าง Export Kerry ระหว่างไลฟ์: จำนวนลูกค้าที่โชว์ ตรงกับจำนวนแถวในไฟล์ Excel ที่ดาวน์โหลด
- [ ] จบไลฟ์ → หน้าต่าง Kerry เปิดเอง และได้ลูกค้าครบทั้งรอบ
- [ ] รวมบิล 2 รอบ (v1.0.15): กด "รอรวมกับรอบหน้า" ตอนจบรอบ A, เริ่มรอบ B, ลูกค้าที่ซื้อทั้งสองรอบเป็นแถวเดียวในไฟล์ Kerry

### ทดสอบหูจริง: เสียงแจ้งเตือน (v1.0.17) — ทำบนเครื่องร้านจริง ข้าง OBS ด้วยลำโพง/หูฟังที่ใช้ตอนไลฟ์
- [ ] เปิดหน้าโปรแกรมใหม่ (F5) ยังไม่แตะอะไร: ป้ายด้านบนต้องเป็นสีเทา "🔇 กดหน้าจอ 1 ครั้งเพื่อเปิดเสียง" → คลิกที่ป้าย: ได้ยินเสียงคิวใหม่ (3 โน้ตไล่ขึ้น) และป้ายเปลี่ยนเป็นสีเขียว "🔔 เสียงแจ้งเตือนเปิดอยู่"
- [ ] ระดับเสียงเดียวกับที่ใช้ไลฟ์จริง ขณะเปิดเพลง/เสียงไลฟ์ใน OBS: เสียงคิวใหม่ต้องได้ยินชัด ถ้ายังเบาไป จดไว้ (ปรับ volume ใน SOUND_PRESETS.newSlip ได้)
- [ ] สลิปปกติเข้าคิว: ดัง 1 ครั้ง (ไม่ดังซ้ำ 2 ครั้งติดกัน)
- [ ] สลิปที่ระบบอ่านยอดไม่ได้ (การ์ดรอใส่ยอด) → แม่ค้ากดใส่ยอดที่พอได้สินค้า: การ์ดได้เลขคิว และได้ยินเสียงคิวใหม่ / ใส่ยอดที่ไม่พอ: ไม่มีเสียงคิวใหม่ (กลายเป็นการ์ดส้ม)
- [ ] สลิปธนาคารกรุงเทพที่ติด 1010: เมื่อระบบตรวจซ้ำเองผ่านและการ์ดได้เลขคิว ต้องได้ยินเสียงคิวใหม่
- [ ] สลับไปหน้าต่าง/แท็บอื่น (เช่น OBS) แล้วให้ลูกค้าส่งสลิป: ยังได้ยินเสียง สลับกลับมาแล้วป้ายยังเป็นสีเขียว
- [ ] ตัวกันเสียงหลุด: เปิดหน้าคิวผ่านลิงก์ท่อบนอีกเครื่อง (เช่น โน้ตบุ๊ก/มือถือ) แตะหน้าจอให้ป้ายเป็นสีเขียว → ปิด Wi-Fi เครื่องนั้น 30 วินาที ระหว่างนั้นให้ลูกค้าส่งสลิป → เปิด Wi-Fi กลับ: เมื่อการ์ดใหม่โผล่ต้องมีเสียงคิวใหม่ 1 ครั้ง (บนเครื่องร้านเองหน้าจอต่อโปรแกรมผ่าน localhost การตัดเน็ตไม่ทำให้หน้าจอหลุด จึงทดสอบข้อนี้บนเครื่องร้านไม่ได้)
- [ ] ลูกค้าโอนไม่ครบ: ได้ยินเสียงโทนเดียว (660Hz) หลังจากแตะหน้าจอไปแล้วครั้งหนึ่ง
- [ ] ข้อจำกัดที่ต้องรู้: เบราว์เซอร์ไม่ยอมให้เว็บเล่นเสียงเองจนกว่าจะมีการแตะ/คลิก/กดปุ่มบนหน้านั้นอย่างน้อย 1 ครั้ง หลังเปิดโปรแกรมหรือกด F5 ทุกครั้ง ให้คลิกป้ายเสียงให้เป็นสีเขียวก่อนเริ่มไลฟ์
