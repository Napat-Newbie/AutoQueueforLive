🚀 Version 1.0.17 LATEST RELEASE
30 ตุลาคม 2026

✨ ปรับปรุง:

  • เอาปุ่ม "📋 คัดลอกข้อความ" ออกทั้งหมด (ทั้งบนการ์ดสีส้มและการ์ดที่ยังไม่มีที่อยู่)
  • แผงควบคุมด้านบนไม่ตรึงตามหน้าจออีกแล้ว ตรึงเฉพาะ "ยอดโอนรวม": เมื่อเลื่อนจนการ์ดยอดโอนรวมพ้นจอ จะมีป้ายเล็กแสดงยอดเดิมลอยที่มุมซ้ายบน (คลิกทะลุได้ ไม่บังปุ่ม)
  • หน้าต่างบอกว่าอัปเดตมีอะไรบ้าง (ก่อนอัปเดตและหลังอัปเดต) ไม่ยาวจนเกินขอบจออีกแล้ว รายการที่ยาวมีแถบเลื่อนอยู่ในกล่อง และปุ่มด้านล่างยังกดได้
  • หน้าประวัติ: สลิปที่ปัดตก/ยกเลิกไม่ถูกนับใน ยอดเงิน สิทธิ์ จำนวนสลิป สรุปสินค้า และรายชื่อลูกค้าอีก (แถวยังเห็นในตาราง) จำนวนสลิปบอกว่าไม่รวมที่ปัดตกกี่ใบ
  • หน้าประวัติ: ลูกค้านับตามรหัส LINE ไม่ใช่ตามชื่อ ลูกค้า 2 คนที่ชื่อ LINE ซ้ำกันไม่ถูกรวมเป็นคนเดียว และสถานะ "รอตรวจรูปสลิป" กับ "เคลียร์ออกจากคิว" แสดงเป็นภาษาไทย (เดิมขึ้นเป็นภาษาอังกฤษ / เหมือน "เสร็จสิ้น")
  • สลิปธนาคารที่ต้องรอหลังโอน (เช่น ธนาคารกรุงเทพ รอประมาณ 7 นาที, SlipOK รหัส 1010) ไม่ขึ้น Error "เครดิตหมด" อีก การ์ดรอใส่ยอดบอกชื่อธนาคารและเวลาที่ให้ลูกค้าส่งรูปเดิมซ้ำ
  • รหัสของ SlipOK อ่านตรงความหมายตามเอกสาร: ธนาคารขัดข้อง / รูปไม่ถูกต้อง / QR ไม่ใช่การชำระเงิน ไม่ถูกนับเป็น "เครดิตหมด" (เดิมทำให้ขึ้นแถบแดงหลอกและสลิปปกติใบถัดไปถูกส่งเข้าคิวตรวจเอง) เครดิตหมดจริงจับจากรหัสแพ็กเกจหมดอายุ/ใช้เกินโควต้า
  • กันนับยอดซ้ำ: ถ้าแม่ค้ากรอกยอดสลิปเองแล้วลูกค้าส่งสลิปใบเดิมซ้ำตอนตรวจผ่าน ระบบผูกเป็นใบเดียวกัน ไม่นับยอดและสิทธิ์ซ้ำ พร้อมการ์ดแดงแจ้ง (ถ้าลูกค้าโอนใหม่จริงทีหลัง ยอดใหม่ยังถูกนับ) และเตือนเมื่อลูกค้ามีรูปรอใส่ยอดค้างอยู่
  • หน้าตั้งค่ามีช่อง "ชื่อบัญชีร้าน (อังกฤษ)" เพิ่ม (ไม่บังคับ) ให้สลิป TrueMoney ที่ SlipOK ตอบชื่อผู้รับเป็นภาษาอังกฤษ ไม่ถูกตีว่าโอนผิดบัญชี ถ้าร้านตั้งชื่อบัญชีเป็นภาษาไทย ให้เข้าไปใส่ชื่ออังกฤษ (ส่วนต้นของชื่อก็พอ) หลังอัปเดต
🚀 Version 1.0.16
29 ตุลาคม 2026

✨ ใหม่:

  • สลิปที่ลูกค้าโอนนอกรอบไลฟ์ (ก่อนกดเริ่มไลฟ์ หรือระหว่างสองรอบ) ถูกผูกเข้ารอบไลฟ์ใหม่อัตโนมัติเมื่อกดเริ่มไลฟ์ ไม่หายจากหน้าคิวอีกต่อไป นับยอดรวมของรอบครบ และออกในไฟล์ Kerry ให้ด้วย (กติกา ก: เงินที่รับก่อนเริ่มรอบถือเป็นของรอบนั้น)
  • ป้ายม่วง "🕒 โอนนอกรอบ" ติดการ์ดคิวถาวรสำหรับยอดที่เงินเข้าตอนไม่มีไลฟ์ (มักเป็นยอดจุ่มที่โอนทีหลังจบไลฟ์) — แม่ค้าเห็นแล้วรู้ทันทีว่าต้องตรวจก่อนส่งของ กันส่งของซ้ำ พร้อมบอกในหน้าประวัติว่ายอดนี้เป็นของรอบไหน
  • ทุกการกระทำของแม่ค้า (เรียกคิว เสร็จสิ้น เคลียร์ กรอกยอดเอง ปิดการ์ด ปัดตก เริ่ม/จบไลฟ์) บันทึกละเอียดพร้อมชื่อลูกค้าและยอดเงิน เข้า system.log และ Discord ช่องบันทึกการใช้งาน (Live Monitor) เพื่อตรวจสอบย้อนหลังได้ว่าใครกดอะไรตอนไหน
  • ข้อผิดพลาดที่ระบบซ่อมเองไม่ได้ (Error ระดับวิกฤต, Error เดิมซ้ำ 5 ครั้งใน 30 นาที, โปรแกรมพังวนซ้ำจนตัวเฝ้าหยุดเปิดใหม่อัตโนมัติ) ส่งข้อความ "📮 ขออัปเดตเวอร์ชันใหม่" เข้าช่องรายงานผู้พัฒนาใน Discord พร้อมร้าน/เวอร์ชัน/สาเหตุ และแนวทางแก้ไข
  • การ์ดแดงแจ้งเตือนสลิปที่ระบบไม่ได้บันทึก ให้แม่ค้าเห็นบนหน้าจอทันที: โอนเข้าบัญชีอื่น, สลิปซ้ำกับของลูกค้าอื่น, และส่งซ้ำใบที่ถูกปัดตกไปแล้ว (เดิมหายเงียบ เหลือแค่บรรทัดใน Logs)
  • บันทึก Log ลงไฟล์ system.log ถาวร ไม่หายเมื่อปิดโปรแกรม หมุนไฟล์อัตโนมัติเมื่อเกิน 2MB ทำให้สืบปัญหาย้อนหลังได้
  • สรุปหลังจบไลฟ์ส่งเข้า Discord ทุกครั้งที่กดจบไลฟ์: สถิติของรอบ (ลูกค้า ยอดรับ สิทธิ์ที่ออก สถานะคิว) พร้อม Error ทั้งหมดที่เจอในรอบและแนวทางแก้ไขรายข้อ และจำนวนคำเตือน
  • ปุ่ม "✏️ แก้ไขสินค้า" บนการ์ดคิว (รอเรียก / เรียกแล้ว / ข้ามแล้ว): ถ้าระบบเลือกสินค้าหรือจำนวนชิ้นให้ไม่ตรงกับที่ลูกค้าต้องการ แม่ค้ากด − / + แก้เองได้ ยอดโอนและสถานะคิวไม่เปลี่ยน ไฟล์ Kerry ใช้รายการที่แก้แล้ว และมีบรรทัดบันทึกว่าแก้จากอะไรเป็นอะไร
  • หน้าต่างแก้ไขสินค้าบอกว่าลูกค้าคนนี้ซื้อรวมกี่ชิ้นในรอบไลฟ์ และได้ส่งฟรีหรือต้องจ่ายค่าส่ง (ครบตามจำนวนที่ตั้งไว้ = ส่งฟรี) พร้อมคำเตือนสีส้มเมื่อการแก้ทำให้ค่าส่งเปลี่ยน หรือเมื่อลดจำนวนชิ้น เพราะเงินที่ลูกค้าโอนไว้จะไม่ถูกคืนเข้ากระเป๋าอัตโนมัติ
  • รูปสลิปที่ระบบอ่านไม่ได้ (รอแม่ค้าตรวจเอง) ถ้าเข้ามาตอนไม่มีไลฟ์ จะติดป้าย "🕒 โอนนอกรอบ" เหมือนสลิปปกติ
  • แผงควบคุมด้านบน (ป้ายสถานะ LIVE / LINE / โควตา / เวอร์ชัน) ตรึงอยู่บนสุดของหน้า เลื่อนดูคิวยาวแล้วไม่หายไปจากสายตา
  • เสียง "ปิ๊ง" ตอนสลิปเข้า และเสียงเตือนโควตาหมด สร้างในเครื่องเอง ไม่ต้องโหลดจากอินเทอร์เน็ตแล้ว เน็ตสะดุดเสียงก็ยังดัง
  • ท่อสัญญาณ (Tunnel) หลุด หรือซิงค์ LINE Webhook ไม่สำเร็จ: ขึ้นแถบสีแดงเต็มความกว้างด้านบนสุดพร้อมเสียงไซเรนซ้ำทุก 30 วินาที (เฉพาะตอนกำลังไลฟ์) กดปิดแถบเพื่อหยุดเสียงได้ รอ 20 วินาทีก่อนเตือน กันเตือนผิดตอนเน็ตกระตุกสั้นๆ
  • เน็ตหลุดแล้วต่อติดอีกครั้ง หน้าจอดึงคิวและสถานะล่าสุดมาใหม่เอง สลิปที่เข้ามาช่วงหลุดไม่ต้องกด F5 เพื่อดู
  • กดปิดโปรแกรมระหว่างกำลังไลฟ์ ต้องยืนยันซ้ำด้วยคำเตือนชัดเจน และโปรแกรมปฏิเสธการปิดถ้าไม่ได้ยืนยัน
  • การ์ดสลิปที่รอแม่ค้าใส่ยอด (อ่านรูปไม่ได้) ไม่ได้เลขคิวและไม่นับเป็นจำนวนคิวรอ เลขคิวของลูกค้าจริงไม่เพี้ยน
  • การ์ดคิวแสดงเวลาที่ลูกค้าโอน และรอมาแล้วกี่นาที (เตือนสีเมื่อรอเกิน 10 / 20 นาที) กับไอคอน "📍 มีที่อยู่จัดส่งแล้ว / ยังไม่มีที่อยู่"
  • แผงด้านบนมีตัวนับ "สลิปล่าสุด: X นาทีที่แล้ว" เปลี่ยนเป็นสีเหลืองถ้าไลฟ์อยู่แต่เงียบเกิน 15 นาที ช่วยสังเกตว่าท่อหรือ LINE ผิดปกติไหม
  • ก่อนเริ่มไลฟ์มีหน้าต่าง "เช็กความพร้อม" รวม 5 จุดไว้ที่เดียว (ท่อ LINE, โควตาตรวจสลิป, รอรวมบิล, เงินค้างที่จะถูกรีเซ็ต, การเชื่อมต่อหน้าจอ) แทนหน้าต่างยืนยันที่เด้งทีละอัน
  • ถ้าผูกลิงก์ท่อสัญญาณกับ LINE Webhook ไม่สำเร็จ (เช่น ขึ้น Invalid webhook endpoint URL) โปรแกรมลองผูกใหม่เองทุก 1 นาทีจนกว่าจะผ่าน ไม่ต้องรอให้แม่ค้ากดปุ่มทดสอบ และข้อความ error บอกชัดว่าลิงก์อะไร ท่อชนิดไหน รหัส HTTP อะไร
  • มีปุ่ม 🔔 แจ้งเตือน เปิดดูประวัติแจ้งเตือน 20 รายการล่าสุด (ท่อหลุด โควตาหมด สลิปซ้ำ โอนผิดบัญชี โอนไม่ครบ สลิปอ่านยอดไม่ได้ ลูกค้าส่งที่อยู่) และมีป้ายแจ้งเตือนชั่วคราวที่มุมจอ
  • สลิปซ้ำและสลิปโอนเข้าผิดบัญชีมีป้ายสีส้มแดงที่มุมขวาบนพร้อมเสียงบี๊ปคู่สั้น และขึ้นเป็นแถวสีแดงบนสุดในตารางยอดโอนล่าสุดด้วย
  • ลูกค้าส่งที่อยู่มาในแชท ไอคอน 📍 บนการ์ดคิวเปลี่ยนเป็นมีที่อยู่ทันที พร้อมป้ายสีเขียวที่มุมซ้ายล่าง (ไม่มีเสียง) ไม่ต้องรอสลิปใบถัดไป
  • สลิปที่ระบบอ่านยอดไม่ได้ (รอแม่ค้าใส่ยอด) มีเสียงคอร์ดเฉพาะ และการ์ดสีส้มกะพริบสั้นๆ ให้เห็นชัด
  • การ์ดสีส้ม (ลูกค้าโอนไม่ครบ) และการ์ดที่ยังไม่มีที่อยู่ มีปุ่ม 📋 คัดลอกข้อความ กดครั้งเดียวแล้วนำไปวางในแชท LINE OA ได้เลย (ระบบไม่ส่งอะไรให้ลูกค้าเอง)

🔧 แก้ไข:

  • หน้าประวัติและหน้าต่าง Kerry โหลดยอดของรอบไลฟ์ที่กำลังไลฟ์อยู่ถูกต้องเมื่อเปิดหน้าระหว่างไลฟ์ (เดิมแสดงเป็นยอดรายวัน) และตัวเลขจำนวนลูกค้าในหน้าต่าง Kerry ตรงกับไฟล์ที่ดาวน์โหลด
  • เพิ่มชุดเทสต์อัตโนมัติ 67 ตัว ครอบคลุมตรรกะเงิน ค่าส่ง การรวมบิล 2 รอบ สลิปนอกรอบ ป้ายโอนนอกรอบ ไฟล์ Kerry และการแจ้งเตือน Discord พร้อมระบบตรวจสอบอัตโนมัติ (CI) ทุกครั้งที่แก้โค้ด
  • โลโกะผู้ให้บริการตรวจสลิปโหลดจากไฟล์แทนการฝังในโค้ด ทำให้แพ็กเกจอัปเดตเล็กลงกว่าครึ่ง

  • ตรวจสลิปซ้ำเร็วขึ้นเมื่อมีประวัติสลิปจำนวนมาก

🚀 Version 1.0.7 Kiro & Claude Opus Certified
16 ตุลาคม 2026

⚡ ความเสถียรภาพระดับไลฟ์สด (Live Stream Stability):

  • Atomic Transaction & Trans Ref: เพิ่มการล็อกความปลอดภัยระดับ SQLite Transaction ป้องกันสลิปยิงซ้ำ (Duplicate Credit) 100%
  • 2-State Dynamic Programming: ปรับปรุงอัลกอริทึมคำนวณสิทธิ์จับรางวัลเป็น 2-State Unbounded Knapsack เร็วขึ้นเหลือ 5.6ms แม่นยำ 100.0%
  • Smart Address Fallback: แก้ไข Bug ชื่อลูกค้า LINE หลุดและเพิ่ม Rule-based Fallback สำรองทันทีเมื่อ AI ออฟไลน์
  • Storage Sentinel Non-blocking: เพิ่ม Uploads Memory Cache 60 วินาที และ In-flight Coalescing ตัดปัญหา I/O คอขวด

🛡️ ยกระดับความปลอดภัยระบบ (Enterprise Security Hardening):

  • Credential Protection: ลบค่า Default Webhook/Tokens ทั้งหมด พร้อมระบบ Scrypt Password Hashing ปลอดภัยระดับอุตสาหกรรม
  • LINE Webhook HMAC Verification: ตรวจสอบลายเซ็นดิจิทัล x-line-signature เพื่อป้องกันการปลอมแปลง Event จากภายนอก
  • Path Traversal & CRLF Defense: ป้องกันการฉีดค่าในไฟล์ระบบและป้องกัน Directory Traversal ตลอดกระบวนการอัปเดต
📦 Version 1.0.6 STABLE
16 ตุลาคม 2026

🛡️ ความปลอดภัย & เสถียรภาพ (Security & Integrity):

  • SEC-01 Checksum: เพิ่มการตรวจสอบรหัสไฟล์ SHA-256 Cryptographic Checksum สกัดกั้นไฟล์อัปเดตที่เสียหายหรือถูกดัดแปลง
  • Redirect Domain Whitelist: บล็อกการ Redirect ออกนอก Official GitHub Release ป้องกันการโจมตีแบบ Open Redirect
  • Path Traversal Sanitization: ล็อกโฟลเดอร์ปลายทางเฉพาะใน updates/ ป้องกันการบันทึกทับไฟล์ระบบภายนอก

⚡ การทำงานพร้อมกัน & ฐานข้อมูล (Concurrency & Performance):

  • BUG-01 Batch Event Isolation: ปรับระบบ LINE Webhook จาก events[0] เป็นวนลูปพร้อม Error Boundary แยกอิสระ (ผ่านการทดสอบ 0.00% Drop Rate)
  • DB-01 SQLite Indexing: เพิ่ม busy_timeout = 10000 พร้อมสร้าง 4 Compound Indices ป้องกันปัญหาฐานข้อมูลล็อก (SQLITE_BUSY)
  • PERF-01 Knapsack Branch-and-Bound: ปรับปรุงการคำนวณสิทธิ์ลุ้น ลดเวลาคำนวณยอดโอนหลักหมื่นจาก 1,029ms เหลือ 0ms (ความถูกต้องตรงเดิม 100%)
  • WAL Truncation: ตั้งค่า wal_checkpoint(TRUNCATE) คืนพื้นที่ดิสก์เป็น 0 bytes อัตโนมัติทุกรอบบำรุงรักษา

🔄 รองรับการไลฟ์ข้ามเที่ยงคืน (Midnight Boundary):

  • BUG-02 & BUG-03: ผูกข้อมูลคิว ยอดเงิน และการส่งออกพัสดุ Kerry Express เข้ากับ session_id ป้องกันยอดเงินและคิวรีเซ็ตตอน 00:00 น.

🔄 การฟื้นฟูระบบอัตโนมัติ (Resilience & Failover):

  • RES-02 Quota Failover: ระบบสลับผู้ให้บริการตรวจสลิปสำรองอัตโนมัติ (SlipOK ➡️ EasySlip / Thunder ➡️ ตรวจภาพเอง) ออเดอร์ไม่สะดุดแม้เครดิตหมด

💬 ปรับปรุงประสบการณ์ลูกค้า & มอนิเตอร์ (UX & Telemetry):

  • MSG-01 ข้อความสไตล์แม่ค้าผักกาด: ตอบกลับสลิปน่ารัก กระชับ เตือนให้ลูกค้าส่งชื่อที่อยู่เบอร์โทรทันที พร้อมแนบลิงก์ LINE OpenChat
